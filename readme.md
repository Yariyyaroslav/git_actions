## 🧩 Що таке GitHub Actions

**GitHub Actions** — це вбудований інструмент автоматизації в GitHub, який дозволяє створювати, тестувати, розгортати та керувати вашим кодом безпосередньо з репозиторію.
Він працює за принципом **CI/CD (Continuous Integration / Continuous Deployment)**, що допомагає прискорити розробку та зменшити кількість ручної роботи.

## ⚙️ Основні поняття

**Workflow (робочий процес)** — це набір автоматизованих кроків, які виконуються при певній події (наприклад, push у репозиторій).

**Job (завдання)** — група кроків, що виконуються на одному віртуальному середовищі.

**Step (крок)** — окрема команда або дія, що виконується в межах job.

**Action (дія)** — готовий до використання блок коду, який виконує певну функцію (наприклад, встановлення Node.js, перевірка коду, деплой).

**Runner (виконавець)** — сервер, який фактично запускає ваші workflow.

## 🚀 Як це працює

1. Ви створюєте файл у своєму репозиторії:
``` bash
.github/workflows/ci.yml
```

2. У цьому файлі описуєте, що має відбуватися при певній події.
Наприклад:
```yaml
name: CI Pipeline

on:
  push:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Set up Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 18

      - name: Install dependencies
        run: npm install

      - name: Run tests
        run: npm test
```

3. Коли ви робите push у гілку main, GitHub автоматично запускає описані кроки.
